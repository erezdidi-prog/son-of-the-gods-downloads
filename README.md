# Son of the Gods

A mythology battle game by Erez Didi.

- Play in the browser: https://sonofthegods.pages.dev
- Android: download `SonOfTheGods.apk` from the latest release on this page and open it on your phone. Android asks once to allow installing from this source.

This is an early test build.
